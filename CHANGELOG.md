# Changelog

## 0.4.0 beta 1 — Video tools

- Added trim, precise crop and movable aspect-preset selections.
- Added Original/CRT filters, optional picture-matched presets, still preview and PNG export.
- Added original audio volume/mute, one added audio file with separate level, delay and fades, plus standalone file listening.
- Added temporary in-app video/audio samples up to ten seconds.
- Added aspect-preserving 1080p/720p bounds, quality presets, and CPU/NVIDIA export.
- Number conflicting MP4/PNG names without replacing existing files.
- Added optional coffee/X links in About; application remains free under GPL-3.0-only.
- Moved to supported .NET 10 LTS; retained selected-application audio and documented capture limits.
- Public ZIP continues to obtain FFmpeg separately through checksum-verified setup.

## 0.3.0 beta — first public release

- Renamed to Capture & Release.
- Added an About dialog with author, license and component credits.
- Preserved Screen and supported Window capture, application-only audio, CPU/NVIDIA encoding, preview, countdown, shortcuts and recovery.
- Settings now use a separate CaptureAndRelease folder, with migration from the earlier names.
- Added one-time, SHA-256-verified upstream FFmpeg setup. Public archives do not bundle FFmpeg binaries.
- Added public build instructions, GPL-3.0-only licensing and documented compatibility/validation limits.
- Excluded personal recordings, settings, local logs, development history and debug symbols from public artifacts.

Earlier Gameplay Recorder and Local Screen Recorder versions were personal test builds.
