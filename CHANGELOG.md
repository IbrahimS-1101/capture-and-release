# Changelog

## 0.3.0 beta — first public release

- Renamed to Capture & Release.
- Added an About dialog with author, license and component credits.
- Preserved Screen and supported Window capture, application-only audio, CPU/NVIDIA encoding, preview, countdown, shortcuts and recovery.
- Settings now use a separate CaptureAndRelease folder, with migration from the earlier names.
- Added one-time, SHA-256-verified upstream FFmpeg setup. Public archives do not bundle FFmpeg binaries.
- Added public build instructions, GPL-3.0-only licensing and documented compatibility/validation limits.
- Excluded personal recordings, settings, local logs, development history and debug symbols from public artifacts.

Earlier Gameplay Recorder and Local Screen Recorder versions were personal test builds.
